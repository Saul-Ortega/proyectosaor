# Ortega_Rodriguez_Saul_UT4A1

## ▶️ Instalación

1. Clonar el proyecto

   ```bash
      git clone https://github.com/Saul-Ortega/proyectosaor.git
   ```

2. Situarse en la carpeta creada

   ```bash
      cd PATH_TO_THE_FOLDER
   ```

3. Instalar las dependencias necesarias

   ```bash
      npm install
   ```

4. Situarse en la carpeta backend

   ```bash
      cd PATH_TO_THE_BACKEND
   ```

5. Ejecutar el fichero index.js con node

   ```bash
      node index.js
   ```

6. Situarse en la carpeta frontend

   ```bash
      cd PATH_TO_THE_FRONTEND
   ```

7. Instalar las dependencias necesarias

   ```bash
      npm install
   ```

8. Por último hay que ejecutar el frontend

   ```bash
      npm run dev
   ```

9. Y ya se puede abrir la aplicación en el navegador

   ```bash
      http://localhost:5173/
   ```
